# OFFSCRIPT® website

An original, responsive multi-page agency website built with plain HTML, CSS, JavaScript, and authored SVG campaign illustrations. No raster art, package installation, or build step is needed.

## Open the site

- Open `index.html` in a browser, or run a local static server from this folder: `python -m http.server 8000`.
- Visit `http://localhost:8000/`.
- `assets/offscript.css`, `assets/offscript.js`, and `assets/offscript-mark.svg` power every page; keep the `assets` folder beside the root pages.

## Pages

- `index.html` — Homepage
- `services.html` — Services directory
- `services/growth-marketing.html`
- `services/web-design.html`
- `services/app-development.html`
- `services/saas-product.html`
- `services/ai-automation.html`
- `services/strategy-creative.html`
- `work.html` — Representative growth plays
- `studio.html` — Studio story and approach
- `contact.html` — Project enquiry

The enquiry form validates the fields and opens a pre-filled email draft. Replace `hello@offscript.studio` in `assets/offscript.js`, `contact.html`, and the page footer before publishing to route enquiries to your inbox. The credentials `1,000+` businesses and `$10M+` client revenue are the claims supplied in the project brief. The work examples are labelled representative strategies, not named client results.
